# Freelancer Management System

A full-stack web application designed to simplify and manage interactions between freelancers, clients, and administrators. The system provides features for project management, freelancer discovery, user authentication, profiles, and centralized administration.

## 🚀 Features

### 👤 User Authentication
- User registration and login
- Role-based access
- Secure authentication
- Separate dashboards for different users

### 💼 Freelancer Features
- Freelancer dashboard
- Create and manage profile
- Find available projects
- View project details
- Manage assigned projects

### 🧑‍💼 Client Features
- Client dashboard
- Create new projects
- Manage posted projects
- Find suitable freelancers
- View freelancer profiles
- Manage project information

### 🛠️ Admin Features
- Admin dashboard
- Manage users
- Manage freelancers and clients
- Monitor projects
- Manage overall platform activities

### 📊 Project Management
- Create projects
- View project details
- Search and explore projects
- Manage project status
- Connect clients with freelancers
